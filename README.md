# تبدیل فرم سوخت به اکسل (Next.js روی Vercel)

عکس فرم را انتخاب کنید و «OCR محلی و رایگان» را بزنید. متن با Tesseract.js در مرورگر خودتان
خوانده می‌شود؛ خود عکس به API یا سرور OCR فرستاده نمی‌شود. نتیجه را پیش از ساخت اکسل بازبینی و
اصلاح کنید، چون OCR عمومی روی دست‌خط فارسی ممکن است اشتباه کند.
همچنین می‌توانید بدون OCR، تعداد ردیف‌ها را وارد کنید و از «ورود دستی بدون API» استفاده کنید.

## اجرا روی Vercel
1. پوشه را در یک ریپوی GitHub بگذارید و در Vercel «Import Project» کنید (تنظیمات پیش‌فرض Next.js کافی است).
2. در Settings → Environment Variables مقدار `APP_PASSWORD` را بگذارید؛ این رمز برای ساخت و دریافت
   فایل اکسل لازم است. `ANTHROPIC_API_KEY` فقط برای مسیر اختیاری «خواندن با API» لازم است.
3. Deploy. در صفحه، رمز را یک‌بار وارد کنید (در مرورگر ذخیره می‌شود).

دکمهٔ «OCR محلی و رایگان» به `ANTHROPIC_API_KEY` نیاز ندارد. این OCR یک موتور تشخیص متن محلی
با دادهٔ آموزش‌دیده است، نه سرویس هوش مصنوعی مولد؛ تشخیص دست‌خط تضمین‌شده نیست و باید بررسی شود.
فایل‌های موتور هنگام `npm run dev` و `npm run build` از وابستگی محلی کپی می‌شوند.

## اجرای محلی
```
npm install
cp .env.example .env.local   # مقادیر را پر کنید
npm run dev
```

## تغییر قالب اکسل
```
node scripts/embed-template.mjs مسیر/فایل-جدید.xlsx
```
قالب فعلی همان فایلی است که فرستادید (داده‌ها از ردیف ۵ شروع می‌شوند).

## تغییر ساختار فرم کاغذی
شرح ستون‌ها و قواعد خواندن در `lib/prompt.js` و حروف/لیتراژهای مجاز در `lib/form.js` است.
