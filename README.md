# تبدیل فرم سوخت به اکسل (Next.js روی Vercel)

عکس فرم دست‌نویس را آپلود می‌کنید، مدل بینایی (Claude) ردیف‌ها را می‌خواند، نتیجه را در جدول قابل‌ویرایش می‌بینید
(ردیف‌های مشکوک زرد) و فایل اکسل با قالب خودتان را دانلود می‌کنید.
در خواندن چندمرحله‌ای، یک بار تصویر اصلی و بار بعد نسخهٔ کمی بهبودکنتراست‌یافته هم خوانده می‌شود؛
اختلاف بین خوانش‌ها برای بازبینی مشخص می‌ماند. بازبینی دستی ردیف‌های زرد همچنان لازم است.

## اجرا روی Vercel
1. پوشه را در یک ریپوی GitHub بگذارید و در Vercel «Import Project» کنید (تنظیمات پیش‌فرض Next.js کافی است).
2. در Settings → Environment Variables این‌ها را بگذارید:
   - `ANTHROPIC_API_KEY`  کلید API
   - `APP_PASSWORD`       یک رمز قوی (بدون آن برنامه کار نمی‌کند؛ جلوی مصرف کلید توسط دیگران را می‌گیرد)
   - `ANTHROPIC_MODEL`    اختیاری، پیش‌فرض `claude-sonnet-5-5`
3. Deploy. در صفحه، رمز را یک‌بار وارد کنید (در مرورگر ذخیره می‌شود).

اگر هنگام تبدیل پیام نبودن `ANTHROPIC_API_KEY` دیدید، مقدار واقعی کلید Anthropic را در
Vercel → Project → Settings → Environment Variables برای محیط Production اضافه کنید
(نه مقدار نمونهٔ `sk-ant-...`) و سپس یک Deploy جدید انجام دهید.

## اجرای محلی
```
npm install
cp .env.example .env.local   # مقادیر را پر کنید
npm run dev
```

## تغییر قالب اکسل
```
node scripts/embed-template.mjs مسیر/فایل-جدید.xlsx
```
قالب فعلی همان فایلی است که فرستادید (داده‌ها از ردیف ۵ شروع می‌شوند).

## تغییر ساختار فرم کاغذی
شرح ستون‌ها و قواعد خواندن در `lib/prompt.js` و حروف/لیتراژهای مجاز در `lib/form.js` است.
